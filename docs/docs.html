Readme

Nexora is a Next-Era Agentic Engine: one platform, every AI, Search → Action. Users discover agents, chat with 10+ models side-by-side, and get Execution Blocks (Export to Sheets, Draft Email, Analyze Code).

Key features

  • Multi-Model Canvas — Compare Claude 3.5 and GPT-4o side-by-side.
  • Verifiable Search — Every claim backed by citations; real-time web verification.
  • Task Orchestration — LangGraph Researcher / Analyst agents.
  • Local-First Caching — Next.js 16 "use cache" for repeated queries.

Tech stack (2026)

Next.js 16.2+, React 19, TypeScript 5.5+, Turbopack, React Compiler · Supabase (PostgreSQL, pgvector) · OpenRouter · Vercel AI SDK v4 · LangGraph.js · Tavily + Firecrawl · proxy.ts · Vercel.

Planning

Vision: One-stop AI destination with Search-to-Action and Execution Blocks. Strategic pillars: Search-to-Action · Agentic Loops (LangGraph) · Unified Canvas · Privacy & Security First.

Target users

Primary MVP: Students + Professionals. Also Developers, Creators, Businesses, Casual users.

P0 — Must have (MVP)

  • Security & privacy baseline (auth, secrets server-side, rate limit, HTTPS, RLS, no PII in logs)
  • User auth (Google + email)
  • Multi-model chat + streaming (OpenRouter)
  • Agentic search with citations (Tavily + optional Firecrawl), "use cache"
  • Core agents (Researcher, Analyst) + task routing + Agent discovery

Privacy & security

Principles: Privacy by design, least privilege, secure by default, transparency. P0: Auth, server-side secrets, proxy.ts rate limiting, HTTPS, RLS, no PII in logs, input validation, npm audit.

Architecture

Request path: Browser → Vercel Edge → Next.js 16 App Router → proxy.ts (rate limit & route) → API Routes / Server Actions → LangGraph (Researcher / Analyst / Coder) + Tavily / Firecrawl / "use cache" → OpenRouter, Supabase, Stripe.

Key decisions

  • proxy.ts — Edge traffic controller; no AI logic in legacy middleware.
  • LangGraph — Stateful agent workflows; router → Researcher / Analyst / Coder.
  • Tavily + Firecrawl — Search + clean markdown for citations.
  • "use cache" — RAG/result persistence; no Redis in core path.
  • Supabase — Auth, PostgreSQL, pgvector, RLS.

Data flows

Chat: useChat → POST /api/chat → proxy → OpenRouter stream → persist message. Agentic search: POST /api/agent → LangGraph router → Researcher (Tavily, Firecrawl, cache) → citations + Execution Blocks → stream. Agent discovery: /discover → /api/agents/search (pgvector) → load agent config for chat/search.

Database

Supabase (PostgreSQL + pgvector). All tables use RLS so users only see their own data.

Core tables

  • profiles — id (auth), email, display_name, avatar_url, tier (free/pro/teams), credits_remaining, timestamps.
  • conversations — id, user_id, title, agent_id, timestamps.
  • messages — id, conversation_id, role, content, model, sources (jsonb), created_at.
  • agents — id, slug, name, description, category, system_prompt, default_model, embedding (vector), is_featured, timestamps.
  • sources — id, message_id, title, url, favicon, snippet, created_at.
  • usage_logs (optional) — user_id, action, model, metadata (no PII), created_at.

Competitors

Research: Perplexity (cited search, Pro $20/mo; weak on actions & niche depth), Genspark (Sparkpages, multi-agent, export; $20–80/mo, complex), AI Fiesta (9+ models ~$12/mo, side-by-side; not search-first, 3 free msgs), Kumari.ai (routing transparency).

Nexora vs them

Search + agents + Execution Blocks from day one; simpler UX & cheaper Pro ($12); transparency (why this agent/model); privacy-first. No slides/video/phone in MVP — we win on cited search + one clear action, then add Canvas and more agents.

Start simple → advance

  • Phase 1: Cited search, one agent (Researcher), one Execution Block, 3–5 model chat, generous free tier.
  • Phase 2: Analyst agent, more actions, Canvas, agent discovery, Pro $12.
  • Phase 3: Transparency UI, Coder agent, 10+ agents, API, privacy/compliance.
